# 商資系 AI 學習知識庫

使用原生 HTML、CSS、JavaScript 製作的靜態學習網站。

## 本機瀏覽
下載並解壓縮後，直接開啟 `index.html`。

## 檔案
- `AGENTS.md`：AI 專案規則。
- `index.html`：首頁。
- `style.css`：共用樣式。
- `script.js`：搜尋及分類功能。
- `genai.html`：GenAI 入門。
- `vibe-coding.html`：Vibe Coding 入門。
- `github-pages.html`：GitHub Pages 入門。
- `database.html`：資料庫與 SQL 基礎。
- 四個 `.md` 檔案：文章 Markdown 筆記。

## GitHub Pages 部署
1. 將本資料夾內所有檔案上傳至 Repository 根目錄。
2. Settings → Pages。
3. Source 選 Deploy from a branch。
4. Branch 選 `main`，資料夾選 `/(root)`，按 Save。
5. 等待部署完成後，使用 GitHub Pages 網址瀏覽。

## 延伸開發
先讓 AI 閱讀 `AGENTS.md`，再要求新增文章。AI 會依照根目錄放置、命名、文章格式、首頁入口及視覺規範延續網站。
