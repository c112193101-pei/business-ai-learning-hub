資料庫與 SQL 基礎

資料庫是有組織地儲存與管理資料的地方，SQL 則是常用來操作關聯式資料庫的語言。

一、資料表的組成

關聯式資料庫通常以資料表（Table）整理資料。欄位（Column）代表資料屬性，紀錄（Row）則代表一筆資料。

二、常見 SQL 指令

  • SELECT：查詢資料。
  • INSERT：新增資料。
  • UPDATE：修改資料。
  • DELETE：刪除資料。

例如：SELECT * FROM students; 代表查詢 students 資料表中的所有欄位與紀錄。

三、學習建議

先熟悉資料表、主鍵與欄位，再練習 SELECT 查詢，接著學習新增、修改、刪除與多表關聯。操作真實資料前，記得先備份。
