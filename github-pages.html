GitHub Pages 入門

GitHub Pages 能將儲存在 GitHub Repository 的靜態網站公開，讓其他人透過網址瀏覽。

一、發布前要準備什麼？

準備好 HTML、CSS、JavaScript 檔案，並確認首頁檔名為 index.html，所有圖片與頁面連結都使用正確的相對路徑。

二、基本發布步驟

  1. 登入 GitHub，建立新的 Repository。
  2. 將網站檔案上傳至 Repository 根目錄。
  3. 開啟 Repository 的 Settings → Pages。
  4. 選擇 Deploy from a branch，Branch 選 main、資料夾選 /(root)。
  5. 儲存後等待部署完成，再開啟 GitHub Pages 提供的網址。

三、常見檢查

如果網頁無法正常顯示，先確認首頁是否為 index.html、檔案是否成功上傳，以及 CSS、JavaScript 和圖片路徑是否正確。更新內容後，可能需要稍等部署完成。
