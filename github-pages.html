GitHub Pages 入門

GitHub Pages 能將儲存在 GitHub Repository 的靜態網站公開，讓其他人透過網址瀏覽。

一、發布前要準備什麼？

準備 HTML、CSS、JavaScript 檔案，並確認首頁檔名為 index.html，資源使用正確相對路徑。

二、基本發布步驟

  1. 登入 GitHub，建立 Repository。
  2. 將網站檔案上傳至 Repository 根目錄。
  3. 開啟 Settings → Pages。
  4. 選擇 Deploy from a branch，Branch 選 main、資料夾選 /(root)。
  5. 等待部署完成，再開啟 GitHub Pages 網址。

三、常見檢查

確認首頁為 index.html、檔案已上傳，以及 CSS、JavaScript 路徑正確。更新後稍等部署完成。
